# Aďo Škuťo — Web Design Manual

Design reference for the static one-page website of personal trainer Aďo Škuťo.

This manual is written primarily for coding agents and developers.

## Page structure

The page contains only:

1. Hero
2. Services
3. Testimonials
4. Footer
5. Service questionnaire modals

Do not introduce additional marketing sections unless explicitly requested.

## Reading order

1. `design-tokens.md`
2. `layout-and-components.md`
3. `motion-and-responsive.md`
4. `questionnaire.md`
5. `visual-ai-prompts.md`
6. `implementation-mapping.md`

## Design direction

The selected direction is **Editorial Coach Profile**.

The page combines:

- authentic coach photography
- editorial typography
- artistic fitness illustrations
- cream, brown and blue colors
- controlled asymmetry
- overlapping visual layers
- clean functional forms

## Non-negotiable rules

1. The hero uses a real photograph of the coach.
2. Services do not use visible numbers.
3. Each questionnaire step contains an illustration.
4. The questionnaire displays a progress bar.
5. The page behind an open modal is blurred.
6. Testimonials are dark chat screenshots in a layered carousel.
7. Illustrations must follow `visual-ai-prompts.md`.
8. Mobile usability takes priority over decorative overlaps.

## General tone

The result must feel:

- professional
- athletic
- personal
- classy
- artistic
- confident

It must not resemble:

- a café
- a wellness spa
- a bodybuilding supplement shop
- a generic gym template
- a corporate SaaS website
